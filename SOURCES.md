# Sources

Every number in Hold'em Trainer is either **computed by the app's own engine** (exact enumeration or combinatorics, unit-tested) or **traced to a source below**. Sources were checked on **2026-11-19** unless noted.

Information is labelled in the UI as one of three kinds:

| Label | Meaning | Where it comes from |
|---|---|---|
| **Math fact** | Exact, computed by code | `src/engine/*`, cross-checked against the references in §1 |
| **Theory baseline** | Published charts / theory, a model with assumptions | §2 (charts) and §3 (concepts) |
| **Practical advice** | Exploitative, home-game advice; not math | Written for this app, always labelled and hideable (Settings → Home-game exploit notes) |

## 2. Preflop charts (theory baselines)

| Source | Used for | Assumptions stated by the source | Notes |
|---|---|---|---|
| [PokerCoaching.com (Jonathan Little) — Free Preflop Charts](https://pokercoaching.com/preflop-charts/) | **6-max RFI** (LJ/UTG, HJ, CO, BTN, SB) and **full-ring RFI** (UTG, UTG+1, LJ, HJ, CO, BTN, SB) | 6-max: 100bb, raise 2.5bb first in, 3bb from SB; "implementable" charts simplify solver mixes to one action per hand. Full ring: published for **8 players**; same raise sizes; stack depth not restated. Rake not stated. | Free text lists on the page, no signup. The text lists differ from the page's printed percentages by up to 0.9 points (they summarise chart images); the app shows the % computed from the text it uses. **Adapted for 9-handed:** the source has no 9th seat, so UTG and UTG+1 both use the source's UTG list and MP uses its UTG+1 list. 6-max's first seat is labelled "LJ" by the source and used as UTG. |
| [Poker Skill — Free preflop charts](https://www.pokerskill.com/charts/preflop/) (updated 16 Nov 2026) | **BTN vs CO open** (3-bet / call / fold) | 6-max cash, ~100bb, CO opens 2.5bb; simplified teaching range (one action per hand), **not solver output** — stated by the source. | Text ranges reproduce the published % exactly. |
| [Poker Skill — Opening ranges by position](https://www.pokerskill.com/charts/opening-ranges/) (updated 2 Nov 2026) | **BB vs BTN open** (defend range) | 6-max, ~100bb, facing a button raise; one "defend" range (calls and 3-bets not separated). | Graded: call or 3-bet acceptable, fold a mistake. |

Alternatives exist and disagree in places — e.g. [Upswing Poker's free 6-max RFI article](https://upswingpoker.com/preflop-open-strategy-rfi-explained/) (2016; ~2.25bb opens; UTG 16%, BTN 40.9%). One source is used per table format for consistency.

Not used (gated): Upswing Preflop Prodigy and PokerCoaching's downloadable PDF charts require an email/account. GTO Wizard solutions require an account.

## 4. Scenario grading

- **Chart spots** (procedural preflop, and library spots marked `"basis": "chart"`): graded against the charts in §2. Mixed actions → "Acceptable".
- **Math spots** (procedural postflop, and library spots marked `"basis": "equity"`): equity vs a **stated** villain range compared with required equity B/(P+2B); ±3 points counts as close (both call and fold acceptable). The assumed range is shown with every spot.
- **Authored spots** (`"basis": "authored"`): written rationale based on the theory in §3, with engine numbers (equity vs the stated range) filled into the text. `tests/library.test.ts` recomputes every stored number and checks that "call"/"fold" recommendations are consistent with the price unless the spot is explicitly an implied-odds call.
